## 1. 模型(`-mosaic_ledger_sync {oracle|strong|snap|none}` + `-mosaic_sync_us T`)

信息拆两类:**charges**(分配声明——确定性重放假设下各 rank 可从
共享输入算出,除 none 外全模式活视图;重放输入 = demand 矩阵,
alltoallv 语义自带全局交换,t=0 免费)与 **discharges/有效速率**
(资源属主的物理观测,须遥测):

| 模式 | discharge/rate 视图 | 发射 | 现实对应 |
|---|---|---|---|
| oracle | 活(零成本) | 即时 | 不可实现,仅上界参考 |
| strong | 触发时刻快照 | **延迟 T**(阻塞 allgather) | BSP 逐波 allgather |
| snap | 周期 T 快照(不阻塞) | 即时 | SSP 有界陈旧 / HPCC-INT 带内遥测 |
| none | 仅本源自己的链 | 即时 | 完全无交换(速率只能用额定,检测器失效) |

实现:`_lg_chg/_lg_dis` 拆分、`lg_view_out/rate` 按模式取视图、
runtime 兼 EventSource(snap 周期事件 / strong 延迟发射队列,
携带触发时刻快照)。回归:legacy λ 8418.42 逐位、oracle 重构后
7907.21 逐位(= x41 LU)。

## 3. 读数

1. **有界陈旧遥测(snap ≤500µs)≈ oracle(±1%),100µs 处连降速
   旗舰都完整保留**——账本的价值不依赖精确同步,只依赖"不太旧的
   计数"。陈旧甚至轻微有益(保守的 level 自带余量,anti-windup 味)。
2. **阻塞式强同步只在 T≤20-100µs 可行**;T=500µs 与波节奏同阶,
   直接把波流水线打断(+30-66%)。结论:分布式形态应选"非阻塞
   周期遥测",不选逐波 barrier。
3. **none 的双面**:中强区 +8-16%(且降速完全失守)⇒ 不可整体
   采用;但在深饱和 nv=90 全场最佳(16274.6,比 oracle 还好
   1.8%)——**视图分歧 = 天然的羊群抑制**:全局同视图让所有 sender
   同时涌向同一"最闲"资源,分歧视图天然错开。这与 @90 恰是账本
   税区互为印证,也给出该税区的候选解方向(有意注入视图抖动/
   本地化,而非更精确的同步)。
4. **回滚判定:不回滚**——snap-100 在 2400/360 反超 λ(1.031×/
   1.015×),降速 2.27×/2.37×,90 仍是已知税点(0.937×);λ 自身
   的现实同步(接收端测 + 每波 λ 广播)与 snap 同量级,不构成
   相对优势。
5. **T=100µs 的规模账**:每 GPU 每周期发布 32B(自己 4 口计数),
   n=1024 时全量 allgather 32KB/100µs ≈ 2.6Gbps = 1.4% NIC 带宽;
   INT/HPCC 式捎带则近零。技术路线谱系:SSP(有界陈旧参数服务器)、
   HPCC/INT(带内逐跳遥测)、确定性重放(SPMD ranks 同输入同算法,
   NCCL 各 rank 独立算同一 ring/tree 的先例)、posted-level 定价
   (对偶分解)。无一是银弹,全部有已部署先例。
