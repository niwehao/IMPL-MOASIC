## 1. O1:波内配对着色 `-mosaic_pair_color[_auto]`

**机制与数学**。MOSAIC 的 chain 以 `epoch = wave*4 + hop` 注入,节点
min-epoch 选包。O1 把编码扩为

```
epoch = (wave*4 + hop)·K + ((d − s) mod K),  K = n
```

即在同一 (wave, hop) 层内按 **Z_n 的 Cayley 表** `L(s,d) = (d−s) mod n`
排序。固定子槽 c,集合 `D_c = {(s, s+c mod n)}` 是一个循环置换:每个
src 恰好偏好一个 dst、每个 dst 恰被一个 src 偏好(Latin square 行)。
因此波内的发送偏好序 = 把 demand 矩阵沿循环置换族做 **BvN 型分解**,
这正是 FAST 全局 permutation 协调的软形式——区别在 min-epoch 只是
偏好不是闸:高优先级 chunk 不可发时低优先级顶上,work-conserving,
skew 稳健性不受损。

**自动门(diag CoV)**。uniform 时上述分解是**等权** BvN(每置换权重
相同),时间片与负载对齐;判别统计量 = 对角线和
`Σ_s D[s][(s+c) mod n]` 的变异系数。关键结构事实:hot-dst 列在每条
对角线上恰出现一次,列 skew 在对角线和中**相消**——实测 zipf1.0/1.5
的 diag_cov = 0.012/0.033(≈0),persrc = 0.237,uniform = 0。门:
`diag_cov < 0.1` 才开(persrc 自动回落 base,实测逐位相同)。

## 2. O3:λ 守卫(负结果)

`-mosaic_guard ε`:λ 更新前预测再平衡收益 `1 − 1/max_c(λ_c/share_c)`
低于 ε 则冻结。实测全部测点(含 nv90)与 base 逐位相同或 ±0.15%:
**M3 的探索保险费不由 λ 漂移承载(exploration floor 才是),守卫无肉**。
flag 保留默认关。"先用模型预测收益、再决定要不要动"这条思路的
守卫半边到此在 EPS 侧证伪:预测式冻结省不出东西。
