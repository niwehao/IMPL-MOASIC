## 读法

- 想知道**现在的方案长什么样** → 不看本目录,直接读主干 §11;
- 想知道**某个机制为什么存在/为什么被退役** → 从它的引入组那篇看起
  (机制与 flag 一律登记在引入它的那篇);
- 想知道**哪些路走不通** → 负结果就写在各篇里(x34 的 O3 守卫、
  x28 的 ramp 退役、x42 的 none 同步档、x44 的确定性重放),
  负结果比正结果值钱,一条都没删。
