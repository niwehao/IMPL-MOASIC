## 结论(v5 设计决定)

1. **采纳 C=6 为新默认**:主线严格支配旧默认,且把 "vs FAST" 从
   "crossover 3.5:1 以下才赢" 升级为 "主线全点 ≥1.00×";机制 = SPREAD 类
   拆成 3 条独立 lane 后,λ 反馈能按 rail 粒度纠偏轮转不均。
2. **代价与诚实边界**:hop 字节 +1~2%(16 组);少数场景相对 C4 小回吐
   (persrc@90 +5%、uniform@360 +3.6%、8h4g@360 +2.6%、zipf1.5/2.0@2400
   +6%/+4%);vs FAST 仍输的残余象限:uniform 强/中侧(0.92-0.95×,FAST
   主场)、persrc@2400(0.95×)、seed44@2400 与 zipf1.5@2400(0.98×)
   ——比 v4 的 ±10% 矩阵依赖收窄到 ≤8%,且全部集中在"强 scale-up +
   温和/全局协调友好负载"这一个象限。
3. threshold 不动(17 组:非敏感旋钮,0.95 的中段回吐否决联动修改)。

复现:01 组命令 + `-mosaic_corridors 6`(变体加 `-mosaic_threshold`)。
