# 45 组:MOSAIC-O-S(`-spectrum`)——伙伴数谱系元调度器

**一句话**:按"每端口伙伴数 = R 账单"把结构候选排成谱系
(M 匹配剥离 / S 收缩与 rot / R2 双向环 / R1 静态 θ 环),纯记账水线
剪枝 + ≤4 次亚秒干跑 + 波机(O-A)作为第五个被实测的候选,argmin
执行;漂移时表侧差分合并(raise/世代/接管),环带 regime 由 1%
margin 门交给波机(漂移吸收期权)。
